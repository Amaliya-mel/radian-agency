# Radian — independent agency analogue

This is a standalone creative-studio concept built from scratch as an independent analogue of an agency template. It uses a new brand, copy, layout, CSS, JavaScript and original SVG artwork. The source archive was left untouched.

## Pages

- `index.html` — studio landing page, selected work, services, proof and CTA
- `work.html` — filterable project index and process
- `contact.html` — project enquiry form demo and studio details

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173/agency-analog/` from the parent directory.

The enquiry form is a front-end demo. Connect Formspree, Netlify Forms or a backend before accepting real submissions.
